What this fixes

The failure modes every n8n operator hits eventually.

Silent failures

Executions that "succeed" while dropping records. Missing error branches, zero retries, swallowed 429s. I make the failure visible, then fix it.

Broken data mapping

JavaScript and Python nodes that stopped matching upstream API changes. One bounded mapping bug fixed per rescue.

Exposed webhooks

Production webhooks with no authentication, callable by anyone who finds the URL. Closed and verified in the report.

Plaintext credentials

API keys sitting in code nodes or plain fields instead of the credential store. Migrated and confirmed.
